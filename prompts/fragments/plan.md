# Tâche : établir le plan détaillé d'une présentation exhaustive

Tu prépares le plan d'un support pédagogique qui devra **tout expliquer** du
contenu étudié. Tu ne rédiges pas encore les slides : tu produis le plan le plus
complet possible, qui servira à l'étape suivante.

## Livrable

Écris **un seul fichier** : le plan décrit en tête de ce prompt (`plan.md` dans
le dossier de sortie). Aucun autre fichier.

Le plan doit :

- lister **tous les points importants** à expliquer, organisés en sections
  cohérentes (thématiques plutôt qu'article par article quand il y a plusieurs
  sources) ;
- pour chaque point, indiquer les **données, chiffres et résultats** clés qui
  doivent être présentés ;
- associer les **figures/tables** pertinentes (chemins exacts) ;
- signaler les **convergences et divergences** entre sources, ainsi que les
  **limites** des données ;
- ne rien inventer : uniquement ce que contiennent les sources.

Pas de limite de longueur. Sois exhaustif, mais sans remplissage.
